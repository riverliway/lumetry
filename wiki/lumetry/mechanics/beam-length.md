# beam-length

[Prof. Candela](#lumetry/characters/prof-candela.md)'s constraint. Beams stop being infinite: a beam now carries only so far before it dies, so distance becomes a resource the player spends.

Every bounce off a [mirror](#lumetry/mechanics/pushable-mirrors.md) eats into the remaining reach, and a beam that dies one cell short of a [detector](#lumetry/mechanics/detectors.md) fails the same as one aimed the wrong way. The mechanic pushes efficient routing: the shortest path that still touches everything it must, no reflection wasted.
